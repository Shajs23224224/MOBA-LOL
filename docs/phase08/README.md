# Fase 8 — aprendizaje continuo offline (0.8.0)

Implementación PyTorch de un módulo Actor-Critic auxiliar (no las redes de salida definitivas), con 256 entradas, proyección de 64, tres alternativas abstractas, crítico de valor escalar, predictor de 256 características siguientes y LoRA de rango 4 sobre una proyección base congelada. 34.628 parámetros totales, 18.180 entrenables, 1.280 de LoRA. Se conserva el banco de 824 expertos sin entrenar: expert_features permite usar su salida congelada como representación opcional, y se probó esa conexión con un experto completo. No se actualizan sus pesos ni el enrutador. Se debe mantener idéntica representación, experto, escala y significado de acciones en todos los registros y checkpoints; no se verifica automáticamente esa identidad.

El replay SQLite guarda hasta 4.096 experiencias por partición por defecto, elimina las antiguas y rechaza duplicados presentes de episodio/paso. División determinista por hash del episodio evita fuga directa entre entrenamiento y validación; no detecta episodios duplicados con distintos IDs. Los registros requieren declaración de autorización explícita (no verifica derechos externamente), estados y siguientes estados finitos de 256 dimensiones, acción entera 0–2, recompensa [-1,1], terminación y probabilidad conocida de la política de comportamiento. Se usan exclusivamente datos registrados; no hay captura ni ejecución de acciones ni entrenamiento en partidas en vivo. El modo CLI realiza una actualización por invocación, puede retomarse desde el checkpoint y no es un proceso autónomo en segundo plano.

Actor ponderado por ventaja exponencial, crítico por objetivo TD(0) con descuento .95, predicción autosupervisada de características siguientes, penalización KL respecto al modelo anterior, Adam, minibatches de 64 y clipping de gradientes. Es aprendizaje offline, no PPO ni un actor-critic online. La LoRA es propia de PyTorch, no usa PEFT. TorchRL y PEFT no estaban instalados; no se simula su presencia. El modelo candidato se entrena en copia. Solo se activa si mejora la recompensa estimada IPS de validación en más de .0001, el MSE TD no empeora más de .05 y, si se proporciona un conjunto histórico disjunto, su recompensa IPS no cae más de .05. La predicción se mide pero no es criterio de aceptación. La IPS depende de propensiones fiables, soporte y representatividad, estima recompensa inmediata y no retorno multietapa. No hay intervalo de confianza ni garantía de mejora real. La validación puede reutilizarse en rondas sucesivas, por lo que no es una prueba final independiente. Replay, KL y ancla opcional mitigan olvido; no lo eliminan. El ancla no se usa para entrenar. Los checkpoints safetensors guardan todos los tensores del módulo auxiliar y un puntero activo JSON atómico con hash SHA-256; no guardan el optimizador. Se recomienda un único escritor; no hay limpieza automática de versiones ni recuperación automática de un checkpoint corrupto. Los archivos se guardan localmente, no se publican pesos en GitHub.

## Reproducción

Instalar pip install -e ".[neural,vision,memory,dev,reasoning-jax]" y Tesseract para regresión completa.

- python -m aion.learning_demo : diagnóstico sintético reproducible, usa directorio temporal y lo elimina al terminar.
- python -m aion.learning_cli --root data/learning --input experiencias.jsonl --epochs 25 : cada línea contiene un Experience conforme al contrato; solo datos autorizados.
- python -m aion.learning_cli --root data/learning --epochs 10 --anchor historico.jsonl : reanudar, evaluar el ancla histórica opcional y publicar checkpoint local solo si pasa los umbrales.
- python -m pytest -q

## Resultados

54 pruebas locales aprobadas (49 anteriores y 5 nuevas) en Linux, Python 3.13.5 y PyTorch 2.10.0+cpu. Pruebas nuevas: autorización declarada, persistencia y capacidad, separación por episodio, actualización real de LoRA y congelación de base, restauración exacta y detección de alteración, rechazo sin modificación de política, validación de ancla, segunda actualización y conexión a un experto de Fase 2. smoke.json registra un entrenamiento real de 25 épocas con 540 registros sintéticos (180 contextos, tres alternativas, recompensa terminal), 423 entrenamiento y 117 validación; recompensa IPS -0.321419 a 0.533198, MSE TD 1.075331 a .889056, MSE predictivo .009581 a .000415. No es un dataset ni una métrica de League of Legends. El checkpoint diagnóstico se verificó tensor por tensor y se eliminó al terminar; no es un modelo distribuido. Se añade una política auxiliar pequeña, no se entrena la arquitectura completa.
