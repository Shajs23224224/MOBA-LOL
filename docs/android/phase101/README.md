# Android 0.10.1 — integración nativa parcial

NeuralPort conserva las dimensiones de las 34 redes de Fase 9, con 2.163.411 parámetros FP32 (8.653.644 bytes de pesos), y calcula 1.107 salidas diagnósticas. Se pueden importar hasta dos representaciones de expertos de subsistemas distintos. El lector AEN1 ejecuta un experto completo de 64.061.696 parámetros, 16 capas ocultas de 2.048, GELU aproximado, LayerNorm y residuales, leyendo secuencialmente los pesos en vez de reservar el tensor denso. El archivo de cada experto ocupa 256.246.828 bytes (incluye cabecera y SHA-256). No hay cuantización, router aprendido ni selección automática en Android; el ID se selecciona explícitamente y solo se conserva la salida de 256 valores. La prueba de paridad se ejecutó con JVM -Xmx64m, no es una medición de RAM total ni de latencia Android. No se incluyen pesos entrenados.

Exportar desde el núcleo Python:
- python -m aion.mobile_neural fusion.bin
- python -m aion.mobile_neural expert.bin --expert 1
- opcional --checkpoint ruta.safetensors, con tensores de la arquitectura correspondiente.
Los formatos AFN1 y AEN1 son big endian, cabecera de 12 bytes, floats y SHA-256 de 32 bytes. Hash verifica integridad, no procedencia. Importar en Integración cognitiva de la app. No se requieren servicios remotos una vez importados los pesos. No se garantiza compatibilidad semántica entre vectores y checkpoints. La pantalla anterior aporta vector sintético o importado y salida del Actor-Critic si disponible. La imagen del laboratorio móvil no se fusiona automáticamente con estos modelos.

CognitiveStore implementa ocho categorías con 32 registros cada una, 256 características por registro, búsqueda euclídea, notas de hasta 1024 caracteres, persistencia privada con reemplazo atómico y validación de estructura (sin checksum). No es SQLite ni memoria aprendida; un archivo privado, sin múltiples scopes o recuperación de archivos corruptos. MobileCouncil recorre 160 IDs de roles, deduplica fuentes y detecta contradicciones; es una revisión de una alternativa suministrada, no el consejo completo multiopción ni 160 inteligencias especializadas. Incluye clausura Horn y actualización bayesiana escalar. La UI pasa evidencias vacías, por lo que todos se abstienen; rellena indicadores de existencia de memoria, no todas las 32 características originales. Las notas semánticas y procedimentales son manuales; seis categorías registran diagnósticos, no hechos observados. Las funciones de lógica y creencias son APIs verificadas, aún no conectadas al flujo visual. El pipeline requiere revisión y no controla juegos. Se mantiene el laboratorio de aprendizaje supervisado previo.

Verificación Linux JVM: 2 pruebas nuevas de paridad (1.107 salidas de fusión, 256 del experto N001; tolerancias absolutas 3e-6 y 3e-5 respectivamente, relativas 3e-5 y 5e-5; corrupción de fusión e ID erróneo de experto rechazados), una prueba de memoria, 160 roles, deducción y Bayes. 63 pruebas totales en dos ejecuciones (49 + 14). La actividad Android y los tiempos en teléfono no se probaron localmente. CI: la primera ejecución 45872760544 falló por paquete tools obsoleto; segunda 45873252106 por sdkmanager fuera del PATH; se corrige con búsqueda dentro del SDK.
