# Android 0.10.0 — laboratorio móvil y compilación CI

El perfil MobileLab es adicional al Actor-Critic de 34.628 parámetros y a las 858 estructuras originales. No sustituye ni entrena esas redes. Usa Java sin dependencias externas: 192 medias RGB y 64 contrastes horizontales, 256 características propias (no compatibles automáticamente con el vector Python), clasificador softmax de tres etiquetas abstractas con 771 parámetros, gradiente de entropía cruzada, memoria de hasta 192 ejemplos y consulta por distancia euclídea. El usuario importa imágenes autorizadas, asigna etiquetas A/B/C y pulsa Entrenar y validar localmente. No se usan las etiquetas como acciones. No requiere red, PC, pesos descargados, OCR externo ni GPU. No se afirma aprendizaje por refuerzo en Android.

Separación determinista por hash de vector, rechazo de duplicados exactos y etiquetas contradictorias para vectores idénticos; no detecta imágenes casi duplicadas ni separa partidas. Se requieren por clase al menos 4 muestras de entrenamiento y 2 de validación. Se entrena una copia durante 24 épocas; se acepta sólo si disminuye la pérdida de validación y no caen los aciertos. La reutilización de validación y la memoria FIFO no garantizan generalización ni evitan olvido. Los datos y pesos se guardan juntos en archivo privado, con SHA-256, escritura sincronizada y reemplazo atómico; si el sistema de archivos no soporta el movimiento atómico se devuelve error. El checksum detecta corrupción, no certifica procedencia. Un único trabajador local serializa operaciones; no se almacenan imágenes originales en el laboratorio. Se limita la imagen decodificada a 512x512 (hasta 1 MiB de píxeles ARGB y otro 1 MiB para el arreglo), la memoria de ejemplos a 192 y el checkpoint a 199.924 bytes. El límite no es una medición de RAM del proceso. La interfaz Android no ha sido ejecutada.

Prueba JVM real: 150 imágenes sintéticas de colores, 116 entrenamiento y 34 validación; pérdida 1.09861 -> 0.00039, aciertos 14 -> 34 de 34, restauración exacta y corrupción rechazada. 60 pruebas Python/JVM aprobadas en 25.94 s (59 anteriores y una nueva). No son datos de partidas. Android SDK, Gradle y dispositivo no disponibles localmente. La compilación CI queda configurada en .github/workflows/android.yml: JDK17, SDK35, Gradle8.9, prueba JVM, assembleDebug, lintDebug y artefacto debug con SHA256. La ejecución remota y su estado se deben comprobar en Actions; no se declara APK generada sin resultado. El APK debug no es una versión final firmada para distribución.

Migración aún parcial: faltan 824 expertos, 34 integradores, los 160 agentes, 8 memorias completas, razonamiento, planificación, especialización MOBA y entrenamiento Actor-Critic en Android; OCR y detectores externos, modelo del mundo, cuantización y pruebas físicas en Galaxy A21s pendientes. Se conserva el código de las fases 1–9, sus pesos lógicos y todas sus limitaciones. El nuevo perfil suma 771 parámetros físicos, no forma parte de los 858 IDs del catálogo. No hay captura en vivo, overlays, servicios de accesibilidad, inyección de acciones ni automatización del cliente. La aplicación es un laboratorio de investigación, no una IA jugable.
